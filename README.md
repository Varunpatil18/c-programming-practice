# C programming & fundamentals
This repository contain my core C programming exercise and foundational concepts.

## Topics & Concepts Covered
- Dynamic Memory Allocation: Dynamic array resizing (malloc, realloc, free), heap safety, and memory management.
- Search & Sort Algorithms: Binary Search ($O(\log n)$), QuickSort (qsort), and custom function pointer comparators.
- Data Structures: User-defined record modeling with struct and typedef.
- Persistent File I/O: Stream buffering, format parsing, and CSV file serialization (fopen, fscanf, fprintf).
- Core Systems Logic: Control flow, pointer arithmetic, input sanitization, and CLI interface design.
